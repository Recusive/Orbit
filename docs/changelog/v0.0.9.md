# Orbit v0.0.9

May 2026

## New

- **TanStack Virtual chat rendering** — Replaced Virtuoso with TanStack Virtual for chat message rendering, delivering smoother scrolling, faster session switches, and eliminated scroll jitter
- **Measure-once virtualization** — Write-through measurement cache with stream-end snapshots eliminates layout recalculations and scroll position jumps
- **Global navigation history** — Back/forward arrows in the header work across the entire app with browser-like history
- **Multi-source skill discovery** — Skills are now discovered from Claude Code plugins, Codex, and ancestor `.claude/skills` directories
- **Source control change badge** — Actions bar now shows a count badge for uncommitted changes
- **IDE-grade git scaling** — Rust status fingerprinting and concurrency-limited diff fetching handles repos with 34k+ untracked files without OOM
- **Pierre diffs upgrade** — Custom Orbit dark/light themes for inline diffs with instant expansion and background preparation pipeline
- **Image attachment tiles** — SafeImage blob URL sanitization, lightbox viewer, and asset:// protocol support
- **TanStack Query data layer** — Session-scoped data lifecycle with lazy hydration and prefetch scheduling for instant session switching

## Improvements

- Session switching performance with O(1) pointer swaps and frame attribution monitoring
- Stick-to-bottom rewrite using React-state-driven approach
- Streaming performance with RAF delta batching and time-gated reveal
- Narrowed Zustand store subscriptions to reduce unnecessary re-renders
- TooltipProvider re-render barrier
- Chat UI polish: tool truncation, table borders, insight block, inline code style
- SF Symbol icon flash and actions bar slide-in desync fixed
- Activity panel no longer overflows off-screen when sidebar opens
- Model selector and thinking level popover spacing refined

## Security

- Workspace path containment — reject parent traversal (`../`) in file write paths with symlink validation
- Credential redaction — API keys and OAuth tokens stripped from logs and Sentry reports
- IPC diagnostic sanitization — malformed sidecar stdout summarized without leaking payload values
- Traffic light IPC hardening — macOS traffic light commands handle failures gracefully

## Fixes

- Scroll freeze in long conversations with code blocks resolved
- Code block text nodes preserved so Streamdown renders content correctly
- Auto-scroll fires reliably during streaming
- Chat input centered in empty state for new conversations
- TodoBar reads per-session tools and syncs with visual handoff
- Claude SDK updated with turn usage clearing

## Accessibility

- Terminal panel controls now have proper ARIA labels
- Skill scope popover controls labeled for screen readers
- Tool widget expand/collapse buttons have `type="button"` attributes

## Housekeeping

- Removed Agent-backend, OpenCode engine, and Canvas UI Builder — Orbit is now Claude-only
- Removed Terminal-app, perf-monitor, and prompt reference directories
- Removed stale patches directory and `.unimportedrc.json`
- Updated cargo-deny to ignore 6 new transitive Tauri advisories
- Bumped CI actions: `actions/github-script` 8 to 9, `dependabot/fetch-metadata` 2 to 3
- Rust clippy compliance for Rust 1.95 lint changes
- Cleared stale test contracts and quality gate specs
