# Orbit v0.0.9

March 2026

## New

- **Global navigation history** — Back/forward arrows in the header now work across the entire app. Navigate between conversations, settings, vault, file tabs, and editor modes with browser-like history. Keyboard shortcuts: `Ctrl+-` (back) and `Ctrl+Shift+-` (forward)

## Improvements

- Refined model selector and thinking level popover spacing for a tighter, more polished feel
- Fixed thinking level popover clipping when providers expose more options (e.g. OpenAI's extended thinking levels)
- Navigation history no longer tracks sidebar open/close — pressing back won't toggle the sidebar
