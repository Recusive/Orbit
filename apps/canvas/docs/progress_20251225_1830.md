## Cross-Tab Communication Analysis

### Currently Implemented

1. **Canvas → Agent (Error Fixing)**
   - `OrbitCanvasService.setOrbitService(IOrbitService)` injected from app.ts
   - Canvas uses `IOrbitService` to request AI fixes for Sandpack errors
   - Fix responses routed back to canvas via session mapping

   ```typescript
   // In OrbitCanvasService
   setOrbitService(service: IOrbitService): void {
     this.orbitService = service;
     this._register(
       service.onAgentMessage(({ sessionId, message }) => {
         if (sessionId.startsWith(this.FIX_SESSION_PREFIX)) {
           this.handleFixResponse(sessionId, message);
         }
       })
     );
   }
   ```

2. **Browser → Chat Context**
   - Element selection in Browser attaches HTML/CSS to Chat widget
   - Uses `chatWidgetService.revealWidget()` and `attachmentModel.addContext()`

   ```typescript
   // In OrbitBrowserWidget
   const chatWidget = await this.chatWidgetService.revealWidget();
   if (chatWidget) {
     chatWidget.attachmentModel?.addContext({
       id: `element-${Date.now()}`,
       name: this.getElementDisplayName(element),
       value: formattedContext,
       kind: 'element',
     });
   }
   ```

### Not Yet Implemented

1. **Canvas → Browser Preview**
   - Canvas cannot tell Browser "navigate to localhost:3000 to preview this component"
   - Would require: Canvas exports to dev server, sends URL to Browser via shared service

2. **Agent → Canvas Operations**
   - Agent tab cannot directly trigger canvas operations
   - Would require: Shared event emitter or service method calls

3. **Centralized State Events**
   - No cross-tab event bus for real-time state synchronization
   - Each tab manages its own state independently

## Sprint 6 Conclusion

**Status: LARGELY COMPLETE**

The three-tab architecture exists and functions. Each tab:

- Has its own editor input and widget
- Communicates with Extension Host via typed IPC
- Can be opened/switched via OrbitTabSelector

Basic cross-tab sharing exists:

- Canvas uses IOrbitService for error fixing
- Browser attaches context to Chat

**Remaining work for enhanced cross-tab features:**

1. Canvas → Browser preview integration
2. Agent → Canvas state awareness
3. Centralized event bus (if needed)

These are enhancements, not blockers for the current sprint.
