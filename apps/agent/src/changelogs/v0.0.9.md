## New

- **TanStack Virtual chat rendering** — smoother scrolling, faster session switches, eliminated scroll jitter
- **Measure-once virtualization** — write-through measurement cache eliminates layout recalculations
- **Global navigation history** — back/forward arrows across the entire app
- **Multi-source skill discovery** — skills from Claude Code plugins, Codex, and ancestor directories
- **Source control change badge** — uncommitted change count in the actions bar
- **IDE-grade git scaling** — handles repos with 34k+ untracked files without OOM
- **Pierre diffs upgrade** — custom Orbit themes with instant expansion
- **Image attachment tiles** — lightbox viewer with asset:// protocol support
- **TanStack Query data layer** — session-scoped data with lazy hydration

## Security

- Workspace path containment — reject parent traversal in file write paths
- Credential redaction — API keys and OAuth tokens stripped from logs
- IPC diagnostic sanitization — malformed sidecar stdout summarized safely
- Traffic light IPC hardening — graceful failure handling

## Improvements

- Session switching performance with O(1) pointer swaps
- Stick-to-bottom rewrite using React-state-driven approach
- Streaming performance with RAF delta batching
- Narrowed Zustand store subscriptions
- Chat UI polish, accessibility labels, Claude SDK update

## Housekeeping

- Removed OpenCode backend — Orbit is now Claude-only
- Removed dead code directories and stale config files
- Updated cargo-deny for transitive Tauri advisories
- Rust clippy compliance for Rust 1.95
