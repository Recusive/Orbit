## Native Glass Rendering

- macOS frosted glass with wallpaper visibility in sidebar, dialogs, and popovers

## AI Session Titles

- Auto-generated descriptive titles under 2 seconds

## File Explorer

- Drag files into chat, right-click actions (Reveal in Finder, Open, Add to Chat)
- Git status dots, markdown preview toggle, real-time refresh

## Worktree Workspaces

- Fully isolated workspaces per worktree
- Scoped file tree, conversations, and git status

## Branch Management

- Searchable popover for branch switching and creation
- Prefetch on hover

## Improved Diffs

- Unified syntax-highlighted diff viewer with language detection
- Folder grouping, inline status indicators

- Smooth scrolling with natural damping across all panels
- Drag-and-drop context: attach files from explorer, clickable file mention links
- Keyboard shortcuts: ⌘\ (toggle sidebar), ⌘N (new conversation), ⌘T (projects), Shift+Tab (cycle input modes)
- Launch animation: wallpaper fade, logo reveal, sidebar slide
- Conversation skeletons, tool widget cleanup, chat polish
- Clean agent shutdown, resilient session data, pruned worktree metadata
