## Architecture Overhaul

- Tauri + Rust backend replacing Electron
- Significantly smaller binary size and lower memory usage
- Native performance for file operations, process management, and system calls
- Rust memory safety guarantees

## CodeMirror 6 Editor

- Replaced Monaco with lighter weight, mobile-ready architecture
- Cleaner plugin system, VS Code-style interface

## Workspace Tabs

- **Agent Tab:** Deep browser integration, full MCP tool support, browser control, console access
- **Editor Tab:** File explorer, multi-tab editing, syntax highlighting, integrated terminal
- **Canvas Tab:** ShadCN component preview, custom component import, live editing sidebar

## Also New

- Full keyboard shortcut support across Agent, Editor, and Canvas
- Snowflake open-sourced as standalone editor (React, Tauri, Rust, CodeMirror 6)
- Authentication via existing Claude subscription with auth token
