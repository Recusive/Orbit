## Multi-Engine Support

- 200+ models across 20+ providers (Anthropic, OpenAI, Google, AWS Bedrock, Azure, Groq, Mistral, xAI, Cohere, Perplexity, DeepSeek)
- Switch engines in Settings
- Web search, semantic code search, session sharing, subagent spawning, and permission system

## Skills Marketplace

- Browse and install community-built skills directly inside Orbit

## Subagents

- Agent can spawn parallel sub-tasks that run independently with inline status

## Settings Redesign

- Full inline page with grouped navigation (Engine, General, Appearance, Agent, Providers, Commands, Shortcuts, Browser, Editor, Git, Notifications, Tabs)

## Also New

- Slash commands with syntax highlighting and filtering menu
- Image attachments for vision-capable models
- Git diff stats: live count of lines added/removed
- Branch picker: full view with search, inline creation
- Word-by-word streaming, /compact status indicator
- Thinking persistence with accurate durations
- Faster session restore with background pre-warming
- Instant title generation on first message
- App icon picker with light/dark variants
- Inline image preview, SVG rendering with source toggle
- Tool card redesign: plain-language headers, collapsible code search
- Unified color system, frosted glass notifications, blur-reveal transitions
