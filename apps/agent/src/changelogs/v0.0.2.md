## Workspace Tabs

- **Ask Tab:** Conversational ideation interface with read-only tooling and isolated context
- **Agent Tab:** Three operational modes — Plan, Accept, Critique
- **Browser Tab:** Fully integrated Chromium with DevTools integration and Playwright support
- **Canvas Tab:** Component library, animation editor, contextual notes, multi-agent coordination, live editing

## Model Support

- GPT-5 variants, Gemini 3 variants, Claude 4.5 (Haiku/Sonnet/Opus)

## Technical Foundation

- Electron runtime, Monaco editor, unified state management
