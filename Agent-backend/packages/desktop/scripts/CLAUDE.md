# scripts

> **Path:** `Agent-backend/packages/desktop/scripts/`

## Purpose

Build, release, and development preparation scripts for the Tauri desktop app. Includes bundle copying (`copy-bundles.ts`), release JSON finalization (`finalize-latest-json.ts`), pre-dev setup (`predev.ts`), build preparation (`prepare.ts`), and shared utilities (`utils.ts`).

| ------------------- | ----------- | ------------------------------------- |
