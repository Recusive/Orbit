# i18n

> **Path:** `Agent-backend/packages/desktop/src/i18n/`

## Purpose

Desktop app internationalization translations. Contains translation files for 15 languages (Arabic, Brazilian Portuguese, Bosnian, Danish, German, English, Spanish, French, Japanese, Korean, Norwegian, Polish, Russian, Chinese Simplified, Chinese Traditional) plus an `index.ts` barrel export.

## Usage Status

| Product             | Status      | Notes                                    |
| ------------------- | ----------- | ---------------------------------------- |
| Orbit Desktop (SDK) | `reference` | i18n key structure and language coverage |
| Orbit CLI           | `not used`  | CLI has separate i18n handling           |
