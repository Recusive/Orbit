# src

> **Path:** `Agent-backend/packages/desktop/src/`

## Purpose

Desktop app frontend source code for the Tauri desktop client. Contains the app entry point (`entry.tsx`, `index.tsx`), Tauri API bindings (`bindings.ts`), CLI integration (`cli.ts`), native menu setup (`menu.ts`), app updater (`updater.ts`), webview zoom controls (`webview-zoom.ts`), loading screen (`loading.tsx`), global styles (`styles.css`), and i18n translations.
