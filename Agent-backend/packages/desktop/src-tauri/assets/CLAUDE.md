# assets

> **Path:** `Agent-backend/packages/desktop/src-tauri/assets/`

## Purpose

Tauri installer assets for Windows NSIS installer. Contains `nsis-header.bmp` and `nsis-sidebar.bmp` bitmap images used in the Windows installation wizard.

| Product             | Status      | Notes                             |
| ------------------- | ----------- | --------------------------------- |
