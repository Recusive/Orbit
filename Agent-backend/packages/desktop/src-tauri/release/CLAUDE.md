# release

> **Path:** `Agent-backend/packages/desktop/src-tauri/release/`

## Purpose

Release metadata configuration for Linux distribution. Contains `appstream.metainfo.xml` which provides AppStream metadata for Linux package managers (app description, screenshots, release notes).

## Usage Status

| Product             | Status      | Notes                          |
| ------------------- | ----------- | ------------------------------ |
| Orbit Desktop (SDK) | `reference` | Linux release metadata pattern |
| Orbit CLI           | `not used`  | CLI has no AppStream metadata  |
