# android

> **Path:** `Agent-backend/packages/desktop/src-tauri/icons/prod/android/`

## Purpose

Production channel Android app icons in standard Android mipmap density buckets (`mipmap-hdpi` through `mipmap-xxxhdpi`, plus `mipmap-anydpi-v26` for adaptive icons) and `values/` for icon configuration.

## Usage Status

| Product             | Status      | Notes                          |
| ------------------- | ----------- | ------------------------------ |
| Orbit Desktop (SDK) | `reference` | Android icon density structure |
| Orbit CLI           | `not used`  | CLI has no Android build       |
