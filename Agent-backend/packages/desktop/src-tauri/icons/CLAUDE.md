# icons

> **Path:** `Agent-backend/packages/desktop/src-tauri/icons/`

## Purpose

App icons for the Tauri desktop build, organized by release channel (`beta/`, `dev/`, `prod/`). Each channel contains platform-specific icons: `.icns` (macOS), `.ico` (Windows), multiple `.png` sizes (Linux/Windows), `Square*.png` (Windows Store), and subdirectories for `android/` and `ios/` icons.

## Usage Status

| Product             | Status      | Notes                                   |
| ------------------- | ----------- | --------------------------------------- |
| Orbit Desktop (SDK) | `reference` | Multi-channel icon organization pattern |
| Orbit CLI           | `not used`  | CLI has no app icons                    |
