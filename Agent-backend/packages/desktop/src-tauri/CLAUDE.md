# src-tauri

> **Path:** `Agent-backend/packages/desktop/src-tauri/`

## Purpose

Tauri v2 backend configuration and Rust source for the desktop app. Contains Tauri config files (`tauri.conf.json`, `tauri.beta.conf.json`, `tauri.prod.conf.json`), Cargo manifest, build script (`build.rs`), macOS entitlements (`entitlements.plist`), and subdirectories for assets, capabilities, icons, release metadata, and Rust source code.

## Usage Status

| Product             | Status      | Notes                               |
| ------------------- | ----------- | ----------------------------------- |
| Orbit Desktop (SDK) | `reference` | Study Tauri v2 backend architecture |
| Orbit CLI           | `not used`  | CLI uses no Tauri backend           |
