# client

> **Path:** `Agent-backend/packages/sdk/js/src/gen/client/`

## Purpose

Auto-generated HTTP client module for the OpenCode TypeScript SDK (v1). Generated from `packages/sdk/openapi.json` via `./script/generate.ts`.

## Usage Status

| Product             | Status   | Notes                                                              |
| ------------------- | -------- | ------------------------------------------------------------------ |
| Orbit Desktop (SDK) | `active` | SDK client used by desktop app to communicate with OpenCode server |
| Orbit CLI           | `active` | Same                                                               |

## Notes

- **Do not modify manually** — regenerate with `./script/generate.ts` after changing server routes.
- Contains HTTP request/response types and fetch-based client methods.
