## Purpose

v2 API client for the SDK. Contains `index.ts` (v2 entry point/exports), `client.ts` (v2 API client wrapper), `server.ts` (v2 server-side utilities), and `gen/` (auto-generated v2 API client code). This is the newer API version that may eventually replace v1.
