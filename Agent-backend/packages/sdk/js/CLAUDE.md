# js

> **Path:** `Agent-backend/packages/sdk/js/`

## Purpose

JavaScript/TypeScript SDK for the backend API. Contains the client library with auto-generated API clients (v1 and v2), usage examples, build/publish scripts, and SST environment declarations. Built with TypeScript and published as an npm package.

| Product             | Status   | Notes                                        |
| ------------------- | -------- | -------------------------------------------- |
