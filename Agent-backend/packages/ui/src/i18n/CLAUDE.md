# i18n

> **Path:** `Agent-backend/packages/ui/src/i18n/`

## Purpose

UI package internationalization translations. Contains translation files for 17 languages (Arabic, Brazilian Portuguese, Bosnian, Danish, German, English, Spanish, French, Japanese, Korean, Norwegian, Polish, Russian, Thai, Turkish, Chinese Simplified, Chinese Traditional). This is the most complete set of translations in the codebase.

## Usage Status

| Product             | Status     | Notes                                |
| ------------------- | ---------- | ------------------------------------ |
| Orbit Desktop (SDK) | `not used` | Desktop has its own i18n files       |
| Orbit CLI           | `rebuild`  | Translation keys and strings to port |
