# themes

> **Path:** `Agent-backend/packages/ui/src/theme/themes/`

## Purpose

Individual theme definition files in JSON format. Contains 15 themes: Aura, Ayu, Carbonfox, Catppuccin, Dracula, Gruvbox, Monokai, Night Owl, Nord, OC-2, One Dark Pro, Shades of Purple, Solarized, Tokyo Night, and Vesper. Each JSON file defines color tokens following the `desktop-theme.schema.json` schema.

## Usage Status

| Product             | Status     | Notes                                    |
| ------------------- | ---------- | ---------------------------------------- |
| Orbit Desktop (SDK) | `not used` | Desktop has its own theme files          |
| Orbit CLI           | `rebuild`  | Theme JSON files to port for CLI theming |
