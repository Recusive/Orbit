# fonts

> **Path:** `Agent-backend/packages/ui/src/assets/fonts/`

## Purpose

Font files for the UI, primarily monospace Nerd Font variants in WOFF2 format plus Geist and Inter UI fonts. Includes 13+ font families (Fira Code, JetBrains Mono, Hack, IBM Plex Mono, Cascadia Code, etc.) each with regular and bold weights. Also includes Geist (sans-serif) and Inter for UI text in OTF/WOFF2/TTF formats.

## Usage Status

| Product             | Status     | Notes                                       |
| ------------------- | ---------- | ------------------------------------------- |
| Orbit Desktop (SDK) | `not used` | Desktop bundles fonts separately            |
| Orbit CLI           | `rebuild`  | Terminal font selection may reference these |
