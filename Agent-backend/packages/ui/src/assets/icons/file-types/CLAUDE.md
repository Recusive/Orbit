# file-types

> **Path:** `Agent-backend/packages/ui/src/assets/icons/file-types/`

## Purpose

File type and folder icons in SVG format, based on the VS Code Material Icon Theme. Contains 700+ icons covering programming languages, frameworks, config files, folder types (open/closed variants), and tool-specific files. Includes light-mode variants (`*_light.svg`) where applicable.

## Usage Status

| Product             | Status     | Notes                                      |
| ------------------- | ---------- | ------------------------------------------ |
| Orbit Desktop (SDK) | `not used` | Desktop uses its own file icon set         |
| Orbit CLI           | `rebuild`  | File explorer UI will need file-type icons |
