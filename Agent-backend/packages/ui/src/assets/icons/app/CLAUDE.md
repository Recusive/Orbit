# app

> **Path:** `Agent-backend/packages/ui/src/assets/icons/app/`

## Purpose

External application icons in SVG/PNG format. Contains 16 icons for editors and terminal emulators: Android Studio, Cursor, VS Code, Sublime Text, Xcode, Zed (light/dark), TextMate, Ghostty, iTerm2, Warp, Terminal, Finder, File Explorer, PowerShell, and Antigravity.

## Usage Status

| Product             | Status     | Notes                                       |
| ------------------- | ---------- | ------------------------------------------- |
| Orbit Desktop (SDK) | `not used` | Desktop has its own app icons               |
| Orbit CLI           | `rebuild`  | May reference for "open in editor" features |
