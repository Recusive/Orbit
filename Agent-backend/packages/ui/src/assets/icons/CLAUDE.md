# icons

> **Path:** `Agent-backend/packages/ui/src/assets/icons/`

## Purpose

SVG icon assets organized by category: `app/` (16 external app icons like VS Code, Cursor, Xcode, terminal emulators), `file-types/` (700+ file type icons from material-icon-theme), and `provider/` (100+ LLM/AI provider logos).

## Usage Status

| Product             | Status     | Notes                                      |
| ------------------- | ---------- | ------------------------------------------ |
| Orbit Desktop (SDK) | `not used` | Desktop has its own icon system            |
| Orbit CLI           | `rebuild`  | File-type and provider icons may be reused |
