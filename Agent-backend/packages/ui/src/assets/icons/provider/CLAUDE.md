# provider

> **Path:** `Agent-backend/packages/ui/src/assets/icons/provider/`

## Purpose

LLM and AI provider logos in SVG format. Contains 100+ provider icons including Anthropic, OpenAI, Google, AWS Bedrock, Azure, Groq, Mistral, DeepSeek, Ollama, and many regional/specialized providers. Used in model/provider selection UI.

| Product             | Status     | Notes                                       |

| Orbit Desktop (SDK) | `not used` | Desktop has its own provider icons          |
