# assets

> **Path:** `Agent-backend/packages/ui/src/assets/`

## Purpose

Static assets for the UI package. Contains `audio/` (sound effects), `favicon/` (browser favicons and web manifest), `fonts/` (70+ font files including Nerd Font variants), `icons/` (app, file-type, and provider SVG icons), and `images/` (social share images).

## Usage Status

| Product             | Status     | Notes                                |
| ------------------- | ---------- | ------------------------------------ |
| Orbit Desktop (SDK) | `not used` | Desktop bundles its own assets       |
| Orbit CLI           | `rebuild`  | Icons and fonts may be reused in CLI |
