# favicon

> **Path:** `Agent-backend/packages/ui/src/assets/favicon/`

## Purpose

Browser favicon and PWA manifest files. Contains `.ico`, `.svg`, and `.png` favicons at multiple sizes (including v3 variants), Apple touch icons, web app manifest icons (192x192, 512x512), and `site.webmanifest` for PWA configuration.

## Usage Status

| Product             | Status     | Notes                              |
| ------------------- | ---------- | ---------------------------------- |
| Orbit Desktop (SDK) | `not used` | Desktop uses native app icons      |
| Orbit CLI           | `rebuild`  | Web-based CLI UI may need favicons |
