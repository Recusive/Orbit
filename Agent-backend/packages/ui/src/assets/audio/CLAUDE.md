# audio

> **Path:** `Agent-backend/packages/ui/src/assets/audio/`

## Purpose

Sound effect files in AAC format used for UI feedback. Contains 45 audio files across 5 categories: `alert-*.aac` (10 alert sounds), `bip-bop-*.aac` (10 interaction sounds), `nope-*.aac` (12 error/rejection sounds), `staplebops-*.aac` (7 sounds), and `yup-*.aac` (6 confirmation sounds).
