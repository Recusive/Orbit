# styles

> **Path:** `Agent-backend/packages/ui/src/styles/`

## Purpose

Global CSS styles for the UI package. Contains `base.css` (CSS reset/normalize), `colors.css` (color variable definitions), `theme.css` (theme variable mappings), `animations.css` (keyframe animations), `utilities.css` (utility classes), `index.css` (import aggregator), and `tailwind/` subdirectory with Tailwind-specific configuration.

## Usage Status

| Product             | Status     | Notes                                       |
| ------------------- | ---------- | ------------------------------------------- |
| Orbit Desktop (SDK) | `not used` | Desktop has its own CSS architecture        |
| Orbit CLI           | `rebuild`  | Color system and animation patterns to port |
