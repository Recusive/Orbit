# tailwind

> **Path:** `Agent-backend/packages/ui/src/styles/tailwind/`

## Purpose

Tailwind CSS configuration files. Contains `colors.css` (Tailwind color variable mappings to the design system), `utilities.css` (custom Tailwind utility classes), and `index.css` (import aggregator).

## Usage Status

| Product             | Status     | Notes                                   |
| ------------------- | ---------- | --------------------------------------- |
| Orbit Desktop (SDK) | `not used` | Desktop has its own Tailwind setup      |
| Orbit CLI           | `rebuild`  | Tailwind color mappings to port for CLI |
