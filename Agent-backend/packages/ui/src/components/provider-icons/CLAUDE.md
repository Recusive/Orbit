# provider-icons

> **Path:** `Agent-backend/packages/ui/src/components/provider-icons/`

## Purpose

SolidJS component for rendering AI/LLM provider icons. Contains `sprite.svg` (SVG sprite sheet with all provider logos combined) and `types.ts` (TypeScript type definitions for available provider icon names).

## Usage Status

| Product             | Status     | Notes                                      |
| ------------------- | ---------- | ------------------------------------------ |
| Orbit Desktop (SDK) | `not used` | Desktop has its own provider icons         |
| Orbit CLI           | `rebuild`  | SVG sprite and type mappings may be reused |
