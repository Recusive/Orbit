# components

> **Path:** `Agent-backend/packages/ui/src/components/`

## Purpose

SolidJS component library with 175+ components. Each component follows the pattern of `.tsx` (component), `.css` (styles), and `.stories.tsx` (Storybook story). Includes foundational UI primitives (accordion, button, card, checkbox, etc.), specialized components (app-icons, file-icons, provider-icons), and complex widgets (tool visualizations, code editors, chat UI). Built with SolidJS, not React.
