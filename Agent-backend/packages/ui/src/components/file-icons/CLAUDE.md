# file-icons

> **Path:** `Agent-backend/packages/ui/src/components/file-icons/`

## Purpose

SolidJS component for rendering file type icons. Contains `sprite.svg` (SVG sprite sheet with all file-type icons combined) and `types.ts` (TypeScript type definitions for available file icon names).

## Usage Status

| Product             | Status     | Notes                                      |
| ------------------- | ---------- | ------------------------------------------ |
| Orbit Desktop (SDK) | `not used` | Desktop has its own file icon system       |
| Orbit CLI           | `rebuild`  | SVG sprite and type mappings may be reused |
