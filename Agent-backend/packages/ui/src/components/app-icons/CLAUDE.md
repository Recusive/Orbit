# app-icons

> **Path:** `Agent-backend/packages/ui/src/components/app-icons/`

## Purpose

SolidJS component for rendering external application icons. Contains `sprite.svg` (SVG sprite sheet with all app icons combined) and `types.ts` (TypeScript type definitions for available app icon names).

## Usage Status

| Product             | Status     | Notes                               |
| ------------------- | ---------- | ----------------------------------- |
| Orbit Desktop (SDK) | `not used` | Desktop has its own icon components |
| Orbit CLI           | `rebuild`  | SVG sprite pattern may be reused    |
