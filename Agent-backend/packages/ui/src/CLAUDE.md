# src

> **Path:** `Agent-backend/packages/ui/src/`

## Purpose

UI package source root containing the full SolidJS-based component library. Organized into `assets/` (static files), `components/` (175+ SolidJS components), `context/` (providers), `hooks/` (reactive hooks), `i18n/` (translations), `pierre/` (design system utilities), `storybook/` (Storybook helpers), `styles/` (global CSS), and `theme/` (theme system). Also has `custom-elements.d.ts` for web component type declarations.

## Usage Status

| Product             | Status     | Notes                                     |
| ------------------- | ---------- | ----------------------------------------- |
| Orbit Desktop (SDK) | `not used` | Desktop uses its own React components     |
| Orbit CLI           | `rebuild`  | Component library to port/rebuild for CLI |
