# vscode

> **Path:** `Agent-backend/sdks/vscode/`

## Purpose

VS Code extension SDK that integrates the agent backend into VS Code. Contains the extension source, build configuration (esbuild), ESLint config, publish/release scripts, and marketplace image assets.

## Usage Status

| Product             | Status     | Notes                       |
| ------------------- | ---------- | --------------------------- |
| Orbit Desktop (SDK) | `active`   | Primary VS Code integration |
| Orbit CLI           | `not used` | VS Code extension only      |
