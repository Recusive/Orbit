# glossary

> **Path:** `Agent-backend/.opencode/glossary/`

## Purpose

Locale-specific translation glossaries that supplement the translator agent. Each markdown file captures community-learned phrasing preferences, do-not-translate terms, and consistency guidance for a specific language. Used by the `translator` agent when translating documentation across 17 locales.

## Usage Status

| Product             | Status      | Notes                                                         |
| ------------------- | ----------- | ------------------------------------------------------------- |
| Orbit Desktop (SDK) | `not used`  | Orbit does not currently have i18n                            |
| Orbit CLI           | `reference` | Glossary format could be adopted if the CLI adds i18n support |
